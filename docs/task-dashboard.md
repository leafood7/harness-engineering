# 本地任务操作台

应用版本 0.13.0。页面接入现有任务队列、执行记录和独立验收，不使用虚构的任务数据。没有新增运行依赖，也不需要前端安装或构建。

## 启动

```powershell
cd D:\VScodeProgects\harness-engineering
npm run dashboard
```

在浏览器打开命令显示的地址，默认 **http://127.0.0.1:4318**。保持启动窗口运行。按 Ctrl+C 关闭页面服务；已经启动的后台任务继续执行。

默认读取项目 `.harness` 中的队列。首次进入没有任务是正常情况：点击“加入离线示例”，再点击“启动调度”，可直接体验三个文件修复任务。离线示例不调用付费模型。页面不会自动提交任务，也不会自动开始运行。

其他数据目录可明确指定：

```powershell
npm run dashboard -- --state .artifacts/queue-demos/你的演示目录 --port 4319
```

截图中曾运行的 `demo:queue` 使用独立目录。要查看那一批记录，传入当时输出的完整 `state` 路径；不会自动扫描或合并所有测试、历史演示目录。端口被其他程序占用时，使用 `--port` 另选一个端口。

## 页面可以做什么

- 查看全部、等待、执行中、完成、失败、中断、取消任务；搜索任务名称、ID 和目录，每页 50 项。
- 查看实际执行阶段、完成轮次、使用策略、工作目录和 Run ID；复制 Run ID。
- 每两秒更新任务状态；页面隐藏时暂停轮询，重新打开时更新。
- 查看中文执行动态，展开原始记录；读取工作进程日志末尾，下载当前执行报告。
- 查看独立验收各项目的结果、工具次数、已记录 Token 和 SDK 估算费用。
- 取消排队或运行中的任务。运行中先显示取消请求，真正停止后才显示已取消。
- 控制并发数量、启动调度、停止后续派发。停止派发不会终止已经运行的任务。
- 填写本机任务 JSON 文件完整路径，一行一个，批量提交。真实模型任务按自身配置使用模型，可能产生费用；操作台不会把它们替换成模拟任务。

不会展示猜测的“完成百分比”。执行中显示实际阶段，不能保证剩余时间。进程日志可能为空；完整任务过程主要记录在执行动态和 Run 事件中。

## 数据与运行边界

“任务队列”显示指定状态目录的队列项。“执行记录”统一显示该目录的队列、直接执行和恢复子 Run，并按 Run ID 去重；不会扫描其他状态目录。原中断记录不会因子任务完成而被改成成功。页面提供恢复检查及启动入口，继续遵守原有检查点验证。

点击“下载执行报告”返回该 Run 当前的结构化报告，不会任意开放本地文件浏览或整个工作区。动态接口读取最近 80 条原始事件并显示其中主要步骤；完整事件可使用 CLI `inspect <run-id> --events --state <目录>` 查看。进程日志最多展示末尾约 64 KiB。

后台调度独立于页面服务运行。关闭浏览器、关闭操作台启动窗口不会自动停止后台调度。离开前如果不希望派发后续任务，请先点击“停止派发”；需要停止某个任务，则使用对应的“取消任务”。

## 本机访问

服务只监听 `127.0.0.1`，不发布到外网；只接受本机正确 Host。同源页面取得本次启动的操作令牌后，才能提交变更请求；拒绝其他网页跨来源调用。页面不加载第三方脚本或字体，任务文字以转义文本呈现。接口会遮盖当前进程已知的密钥值和常见凭据字段，但不承诺自动识别任务内容中的全部私人信息。

这不是多人远程服务，没有登录系统和外网访问入口。不要将该服务转发为公共网站。应用升级后仍遵守原来的跨版本恢复限制。

## 执行记录与页面恢复

点击左侧“执行记录”，可以查看同一状态目录中的直接执行、队列执行和恢复执行。每一行都标注来源，队列项与对应的 Run 不重复列出。已有进程退出但未留下终态的记录会标成中断，不冒充成功。

选择已取消或已中断记录，点击“检查能否恢复”。通过时显示剩余工具次数、Token、时长，以及继续执行或仅继续验收的模式；点击“继续执行”后会再次核对全部条件，并创建独立的恢复 Run。真实模型任务恢复仍可能产生模型费用，不会自动变成离线任务。

页面恢复通过已有 CLI/引擎执行，没有绕过目录、会话、策略、用量、版本和检查点限制。重复点击或两个页面同时操作，最多创建一个恢复子 Run。原记录保留原状态，关联按钮可在原执行及后续恢复之间切换。

用量是从祖先继承的累计用量，不能简单把父子记录中的数字相加。恢复使用原策略快照，当前默认策略切换不会让旧任务换规则。跨应用版本恢复仍然禁止：旧版本的记录可查看，恢复时需按提示使用原版本处理。没有做自动迁移。

页面恢复不加入队列并发槽，但与 CLI 直接执行、队列执行共用同一状态目录下的工作区占用检查。相同目录和上下级目录不能同时执行；遇到占用会等待或拒绝启动。未知工具结果、无法确认已停止的验收进程会保留保护。不同状态目录及外部手工操作不在此保护内。

## 文件变化

新执行在结束后保存目录观察快照，并把文件摘要绑定到执行事件。“文件变化”比较本次开始与结束的快照，展示新增、修改、删除，最多显示 200 项；不会为查看历史记录而重新扫描当前目录。

旧记录没有结束快照时，只展示最近检查点的变化，并明确说明不是最终产出。快照缺失或不一致时显示不可用，不把当前目录的修改冒充历史结果。观察到变化不等于每个变化都已经通过验收，也不能证明都是任务自身造成的；是否完成仍以独立验收为准。恢复子记录只展示相对它自己开始时的变化，原执行的产出保留在原记录里。

## 更新已有页面服务

已经启动的 Node 服务需要重新启动才能加载新接口。在原启动窗口按 Ctrl+C，再运行原来的 `npm run dashboard`，保留原有 `--state` 和端口参数，然后刷新网页。关闭页面服务不会取消已在后台运行的队列任务。本轮检查使用独立端口，未替用户停止原有 4318 服务。


## 在页面创建任务与复用模板

点击“创建任务”，默认进入表单；原有本机任务文件导入保留在同一窗口的“导入已有任务文件”页签。

1. 填写任务名称、已有工作目录的完整路径和目标。名称支持英文、数字、点、短横线和下划线，首次打开会提供默认名称；目标可用中文。
2. 选择真实模型及其提供方。选项来自已安装 Pi 的本地目录，不联网刷新、不发送模型请求。密钥字段只填写环境变量名称，不能填写密钥值；该变量必须已存在于启动操作台的进程环境，新增变量后需重启服务。
3. 选择当前默认策略或指定版本，勾选允许的读取、写入、编辑和等待工具，设置时长、工具次数、Token 和可选美元费用上限。指定策略仅作用于该任务，不修改默认策略。
4. 选择“文件内容完全匹配”或“已有 .cjs 脚本”作为独立验收。文件路径相对任务工作目录；期望内容包括换行和空格，可为空。脚本须已存在，可用相对工作目录的路径或本机绝对路径；检查配置不会执行脚本。
5. 点击“检查配置”，阅读摘要。修改任何任务配置后需重新检查。提交时后台也会重新校验，然后通过原队列保存独立任务副本。若调度器已运行，新任务可能马上开始，提交不会强行暂停调度。

“离线固定写文件练习”只会把期望内容写入目标文件，再运行独立验收，不会理解任意任务目标；需要允许写入并至少分配一次工具调用。它适合体验创建、排队和结果流程，没有付费模型调用。真实模型任务才用于一般任务执行，费用按实际请求产生。

检查会识别字段格式、目录不存在或范围不适合、越界文件、把目录当验收文件、策略或模型不存在、缺少密钥环境变量、无效预算及缺少验收脚本。检查通过说明配置可提交，不保证模型能完成目标；最终结果仍由原有独立验收判断。

在表单填写模板名称并点击“保存模板”，会保存独立配置快照到当前状态目录的 templates.sqlite；同名再次保存也是新快照，列表显示保存时间，旧模板不会被覆盖。载入后可修改再检查、提交。保存模板不启动任务，也不调用模型；保存的是配置及环境变量名称，不读取该变量的密钥值。目标和期望文本是用户填写内容，仍按本地任务数据保存。

模板保存时检查结构与策略定义；目录、密钥和模型等当前运行条件在使用时重新检查。模板只属于当前状态目录，不跨目录自动同步。模板支持整组重命名和保存新版本；旧版本配置不被覆盖，可以载入历史版本。没有模板删除、附件上传、任意验收脚本编辑或可视化多项验收编辑；复杂配置仍可文件导入，复制或编辑复杂任务时使用完整 JSON 编辑器。

应用版本更新为0.13.0，原有跨应用版本恢复限制保持不变。本轮没有新增依赖、模型效果测评或付费模型调用；表单相关检查记录保存在 validation/task-creation。


## 历史产出与验收详情

“保存的产出文件”可预览执行前后保存的文本、代码和 JSON，查看差异并下载任一侧。JSON 格式化只影响显示，差异和下载保留原文本。单文件最多保存128 KiB，每个阶段文本总额2 MiB；大文件、二进制文件、读取时摘要不一致及超额内容会说明原因。列表最多200项，变化文件优先；差异最多1000行。不是完整工作区备份。

旧记录没有保存文本时不补读今天的文件，历史摘要或证据被修改时拒绝展示。文件变化只是目录观察，不等于全部由任务造成或全部通过验收。下载也遮盖已知密钥，包含未被识别的私人内容仍需自行判断。

“验收结果 → 查看独立验收详情”展示文件期望与实际内容、摘要，或脚本退出码、标准输出和错误输出，并关联对应文件及验收步骤。超大期望文本省略正文、保留大小和摘要；脚本输出有64 KiB上限，完整执行权威仍是原来的独立验收器。

## 复制、编辑和批量管理

“复制为新任务”载入原配置，创建新 Run、使用新预算并保留来源链接；这与继承原会话和累计预算的“继续执行”不同。无法完整放进简单表单的任务进入 JSON 编辑器，保留多轮提示、策略、上下文和多项验收等字段；上方目标字段优先于 JSON 中的目标。

“编辑等待任务”只修改尚未启动的同一个队列项。保存时核对原配置摘要；其他页面修改或调度器已经领取时拒绝保存，不影响运行中任务。队列箭头只调整等待项顺序，不抢占运行任务。

勾选任务可批量取消、归档、取消归档和导出摘要，单次最多100项；逐项返回结果。归档只隐藏终态记录，不删除证据，可通过“已归档”筛选找回。搜索包括目标、名称、ID、目录，并可按来源、日期和状态筛选。

## 默认配置、模板和草稿

“配置与服务”可修改后续新任务默认预算和策略，不改变已提交配置或恢复任务。策略切换核对版本，避免多页面覆盖。环境变量只展示是否设置，不验证密钥有效性，不发送模型请求。

模板重命名作用于同一模板家族；保存新版本保留所有旧版配置。载入后仍需重新检查目录、模型、环境变量和验收条件。

表单与复杂 JSON 草稿自动保存到当前数据目录，浏览器保留本页恢复信息。提交成功会清除当前草稿；延迟保存不会把已清除的草稿重新写回来。同一次提交或等待任务编辑使用持久请求凭据，重复请求返回已有结果；修改内容后生成新请求。提交不等于任务成功。

## 服务升级与数据保留

详情可暂停自动更新，方便阅读长日志；列表仍更新，切换任务或主动操作会恢复详情更新。断开连接时页面提示并尝试重新连接。

配置页显示应用与 Node 版本、启动时间、地址、数据目录和本目录存储量。“停止页面服务”保留后台任务；重启需重新运行原命令。停止派发、取消任务和停止页面服务是三个不同操作。

新页面服务启动时，如发现旧版或未知版本调度器，会停止它继续派发，已启动任务继续运行；之后需显式启动匹配版本调度器。跨应用版本检查点恢复仍被拒绝，旧记录仍可阅读。

安全清理只清除表单草稿及30天前且关联任务已终结的提交凭据；不删除 Run、队列输入、会话、检查点、文件产出或验收证据。归档不会减少磁盘占用。

完整离线功能检查170项通过，最终相关检查22项通过，另完成浏览器交互核对。资料在 validation/workspace-management；这些是功能正确性检查，没有新增模型效果评测或付费调用。

## 执行经验入口

结束的任务详情新增“执行经验与建议”：补充反馈、整理当前执行线索、校验导入建议、编辑与审阅、查看版本历史、导出证据包。复用本地 evolving-harness 的机制，独立保存在 experience.sqlite。使用说明和边界见 execution-experience.md。旧页面服务重启后才能加载该接口。
